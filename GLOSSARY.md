# Glossary

- **Calendar event**: A resource schedule marked for calendar display. A `TRUE*` event needs confirmation before visiting.
- **Short name**: The concise name used to identify a resource in calendar output.
- **Business hours**: Schedule rows for one resource whose event labels are weekdays or weekday ranges; those rows describe one recurring schedule.
- **Named event**: A separately labeled service, such as “Breakfast” or “Pantry,” that remains distinct from other events at the same resource.
- **Unplaced schedule**: A calendar-eligible schedule whose recurrence details are insufficient or variable, so no dates are assigned.
- **Confirmation marker (`*`)**: Indicates that a schedule or holiday occurrence needs confirmation before visiting.
